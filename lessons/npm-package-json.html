npm & package.json

npm is Node's package manager — it installs third-party libraries and package.json is the manifest that describes your project.

The essentials

npm init -y creates a package.json. npm install adds a dependency and records it. npm install saves runtime dependencies; npm install -D saves dev-only ones like testing tools.

  • dependencies — needed to run the app in production
  • devDependencies — only needed while developing (linters, test runners)
  • scripts — shortcuts like "start": "node app.js", run with npm start

Try it live

package.json 
const packageJson = {
  name: "eth-nodejs-app",
  version: "1.0.0",
  scripts: { start: "node app.js", dev: "node --watch app.js" },
  dependencies: { express: "^4.19.2" }
};

console.log(JSON.stringify(packageJson, null, 2));
console.log("\nRun with: npm start");
